# 发布层统一文案片段接入清单

本清单用于检查各入口是否正确复用统一文案片段，避免口径漂移。

## 1. 适用入口

- 单股联合分析文本入口
- 批量概览入口
- 小程序发布摘要入口
- 其他派生通知入口

## 2. 接入前检查

- [ ] 已引用统一片段来源：combined-analysis-output-spec 第11节
- [ ] 已区分 watch/pending 与 confirmed
- [ ] 已保留中枢主口径优先声明
- [ ] 已保留“非投资建议”风险说明

## 3. 场景覆盖检查

### 3.1 预突破但未确认

- [ ] 使用“结构预警（待确认）”标题
- [ ] 明确写出首次回试是否回到中枢
- [ ] 未出现 confirmed 信号措辞

### 3.2 预破位但未确认

- [ ] 使用“中枢监视提醒（非确认信号）”标题
- [ ] 明确写出首次回抽是否回到中枢
- [ ] 建议保持 watch/pending

### 3.3 去向偏反趋势但级别未闭合

- [ ] 使用“背驰后去向观察（级别未闭合）”标题
- [ ] 标明 route_level_from/route_level_to
- [ ] 未升级为确认反转

## 4. 输出一致性抽检

| 抽检项 | 通过标准 | 结果 | 备注 |
| --- | --- | --- | --- |
| 标题一致性 | 使用统一片段标题集合 |  |  |
| 结论一致性 | 预警场景不输出 confirmed |  |  |
| 理由一致性 | 明确首次回抽/回试条件 |  |  |
| 建议一致性 | 统一使用等待确认语气 |  |  |
| 风险声明一致性 | 含中枢主口径优先与免责声明 |  |  |

## 5. 回归建议

- 每次发布前随机抽样至少 10 条文本做人工复核。
- 对不一致文本记录入口、版本、样本ID，并在下个迭代前修复。
- 若出现“预警 -> confirmed”越级文案，按阻塞问题处理。
