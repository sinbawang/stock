# 买卖点与多级别联立规格

本文件定义以下高层消费与执行模块：

- 一二三类买卖点
- 区间套
- 小转大
- 多级别联立
- 操作级别与执行级别分工

这是缠论分析最容易出现“概念懂了，但代码和消费端口径不一致”的模块。

## 1. 当前定位

- 理论成熟度：中高
- 当前实现完成度：低到中
- 当前文档完整度：中低

当前仓库里这部分最需要明确“严格定义”和“当前只到观察提示”的边界。

## 2. 一二三类买卖点

### 2.1 总则

- 买卖点都依附于最近中枢和走势类型。
- 买卖点是结构结论，不是经验信号枚举。
- 任一买卖点都必须能回答“属于哪个最近中枢、位于哪个离开/回抽阶段”。

### 2.2 第一类买卖点

- 第一类买点：下跌走势在最后相关中枢附近出现背驰后，形成向上转折。
- 第一类卖点：上涨走势在最后相关中枢附近出现背驰后，形成向下转折。

核心是“背驰导致的转折”，不是单纯触边。

### 2.3 第二类买卖点

- 第二类买点：第一类买点出现后，第一次回试不破前低，再次恢复向上时形成。
- 第二类卖点：第一类卖点出现后，第一次反抽不破前高，再次恢复向下时形成。

核心是“转折后的第一次确认性回抽”。

### 2.4 第三类买卖点

- 第三类买点：向上离开中枢后，第一次回抽不重新跌回中枢上沿之下，再度走强时形成。
- 第三类卖点：向下离开中枢后，第一次反抽不重新站回中枢下沿之上，再度走弱时形成。

核心是“离开中枢后的首次不回归确认”。

### 2.5 关系约束

- 第二类点与第三类点可能在特定结构下重合。
- 若最近中枢语义不清，买卖点不能给严格确认，只能给观察提示。
- 类中枢路径不得单独提升为严格确认买卖点。

## 3. 区间套

区间套的作用是：

- 高一级给方向和结构位置。
- 当前操作级别给买卖点与风险边界。
- 更低一级给执行节奏、确认窗口和进退精度。

红线：

- 低级别买点不能单独推翻高级别未完成结构。
- 低级别只能提高时机精度，不能直接改写高级别主方向。

## 4. 小转大

小转大应理解为：

- 次级别结构先完成转折。
- 该转折随后被更高级别结构吸收、确认，演化为高级别转向的一部分。

它不是“低级别一有信号，高级别必转”。

严格要求：

- 必须明确低级别转折发生在哪里。
- 必须明确高级别确认依赖哪个结构闭环。
- 若高级别尚未确认，只能表述为“可能的小转大候选”。

## 5. 多级别联立

多级别联立的推荐分工：

- 高级别：方向、结构位置、是否临近关键中枢或关键背驰。
- 操作级别：一二三类买卖点、风险位、观察位。
- 执行级别：区间套确认、入场节奏、再确认窗口。

## 6. 当前实现状态

当前仓库更接近：

- 已有部分 buy/sell 工程规则。
- 已有部分低级别精确执行字段。
- 但严格“最近中枢 -> 背驰 -> 1/2/3 类点 -> 多级别确认/降级”的主链路仍未完全闭环。

因此这部分不应被表述为“已经严格按原文完整实现”。
