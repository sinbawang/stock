# 线段图文化示例库（V1）

本页提供线段模块的图文化示例模板，服务于人工核图、原文复核和工程行为解释。

使用原则：

- 图示必须同时标清“确认笔序列”“当前线段方向”“终结依据”。
- 任何线段终结示例都应区分“理论定义”和“当前工程 stop_reason”。
- 对 67 课第二种情况、71 课再分辨，必须用时序图而不是只写结论。

## 1. 起段三笔公共重叠示例

场景目标：演示为什么前三笔没有公共重叠就不能起段。

```mermaid
flowchart LR
  A[第1笔] --> B[第2笔]
  B --> C[第3笔]
  C --> D{三笔是否存在公共重叠区间}
  D -- 是 --> E[允许作为起段种子]
  D -- 否 --> F[不得起段]
```

图注模板：

- 必填：三笔区间交集。
- 红线：不能只因“方向交替”就判定起段成立。

## 2. 段内两笔一组扩展示例

场景目标：演示当前实现为什么按“反向一笔 + 同向一笔”扩展。

```mermaid
flowchart LR
  A[当前同向推进笔] --> B[反向回撤笔]
  B --> C[下一根同向推进笔]
  C --> D{是否继续创新高/新低}
  D -- 是 --> E[线段延伸]
  D -- 否 --> F[线段停驻/待终结]
```

图注模板：

- 必填：上一同向极值、当前同向极值。
- 说明：这里是当前工程扩展节奏，不是所有原文表述的唯一图法。

## 3. 直接特征序列分型终结示例

场景目标：演示无缺口时的直接终结。

```mermaid
flowchart TD
  A[反向特征序列元素1] --> B[元素2]
  B --> C[元素3]
  C --> D{形成顶/底分型 且 前两元素无缺口?}
  D -- 是 --> E[旧线段直接终结]
  D -- 否 --> F[继续观察]
```

图注模板：

- 必填：是否做过同序列非包含处理。
- 红线：跨特征序列元素不得混入同一次分型判断。

## 4. 67课第二种情况示例

场景目标：演示第一二元素有缺口时不能直接回写终结。

```mermaid
flowchart LR
  A[缺口分型候选] --> B[记为待确认转折点]
  B --> C{后续同向第三笔先破终点?}
  C -- 是 --> D[确认新段成立 旧段终结]
  C -- 否 --> E{后续反向笔先破起点?}
  E -- 是 --> F[旧段延续 撤销候选]
  E -- 否 --> G[继续等待再分辨]
```

图注模板：

- 必填：第一笔起点、第一笔终点、后续比较顺序。
- 红线：有缺口时不得提前把候选分型写成已确认终点。

## 5. 71课再分辨时序示例

场景目标：演示“先破终点”与“先破起点”决定旧段命运。

```mermaid
flowchart TD
  A[缺口候选进入再分辨] --> B{后续先发生什么}
  B --> C[先破第一笔终点]
  B --> D[先破第一笔起点]
  C --> E[旧段终结 新段确认]
  D --> F[旧段延续 候选失效]
```

图注模板：

- 必填：比较对象的时间先后。
- review 重点：这是一条时序决策链，不是静态三点几何比较。

## 6. 理论/工程/消费三层边界示例

场景目标：演示线段模块里最容易被混写的三层口径。

```mermaid
flowchart TD
  A[原文线段定义] --> B[当前工程识别逻辑]
  B --> C[stop_reason / consumer contract]
```

图注模板：

- 理论层：解释什么叫线段确认。
- 工程层：解释当前代码如何算出线段。
- 消费层：解释下游如何读 `stop_reason`，不能反推理论本体。
