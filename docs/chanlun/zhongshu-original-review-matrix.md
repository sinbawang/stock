# 中枢原文复核矩阵（第一版）

本页用于回答两个问题：

- 现有中枢文档是否完全贴合缠论原文。
- 哪些条目已经一致，哪些仍是工程近似或待补。

当前结论：现有文档不是“完全准确”，而是“严格口径 + 工程口径并存”，需要继续做逐课对齐。

## 1. 复核范围（首轮）

首轮拆为两层，共 12 课。

核心层（7课）：

- 第18课：走势类型、中枢定义、延伸与中枢定理基础。
- 第20课：中枢级别扩张、中枢中心定理、第三类买卖点。
- 第21课：三类买卖点完备性与中枢关系。
- 第25课：中枢与 MACD/均线辅助关系边界。
- 第53课：三类买卖点再分辨与级别切换原则。
- 第83课：笔-线段与线段-最小中枢结构差异。
- 第92课：中枢震荡监视与变盘提示。

结构扩展层（5课）：

- 第17课：走势终完美与中枢定义的原始总纲。
- 第29课：背驰-转折定理与“最后中枢扩展/更大级别盘整/反趋势”三分法。
- 第36课：走势类型连接结合律的当下重组，对中枢级别切换有直接约束。
- 第38课：同级别分解唯一性与中枢操作层级边界。
- 第39课：同级别分解的机械节奏与中枢震荡内迭代规则。
