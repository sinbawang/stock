# 中枢「重叠优先 vs 走出优先」专项评审（2026-08-28）

spec_id: SPEC.ZHONGSHU.CORE（见 [zhongshu-core-spec.md](zhongshu-core-spec.md)）。

本文记录对 `identify_zhongshu` 中「后续段与中枢区间重叠 → 并入延伸本体」这一主链
口径的一次专项评审，触发样本为 `03690 5m` 的 S11/S12/S13/S14/S15 窗口。**本文只做
评审，不改代码。**

## 1. 触发样本与现象

`03690 5m`（窗口 `20260722→20260828`，segment 级中枢）相邻段：

| 段 | 方向 | 区间 | 状态 |
| --- | --- | --- | --- |
| S7 | 下 | 92.05 ~ 93.95 | confirmed |
| S8 | 上 | 92.05 ~ 96.45 | confirmed |
| S9 | 下 | 89.80 ~ 96.45 | confirmed |
| S10 | 上 | 89.80 ~ 92.20 | confirmed |
| S11 | 下 | 85.70 ~ 92.20 | confirmed |
| S12 | 上 | 85.70 ~ 88.75 | confirmed |
| S13 | 下 | 84.05 ~ 88.75 | confirmed |
| S14 | 上 | 84.05 ~ 89.35 | confirmed |
| S15 | 下 | 83.30 ~ 89.35 | confirmed |

当前 `identify_zhongshu(..., structure_level="segment")` 只产出 2 个中枢：

- ZS0：进入 S0，核心 S1/S2/S3，区间 `[89.00, 91.35]`，本体延伸至 S6。
- ZS1：进入 S7，核心 S8/S9/S10，区间 `[92.05, 92.20]`，本体延伸至 S11。

而「S11(进)+S12/S13/S14」「S12(进)+S13/S14/S15」两个本应有效的窗口都被跳过。

## 2. 根因链（证据）

1. ZS1 的核心 S8/S9/S10 的三重叠加只有 `[92.05, 92.20]`（宽 0.15）。
2. S11（下，`85.70~92.20`）与 `[92.05, 92.20]` 有弱重叠：
   `max(92.05, 85.70)=92.05 < min(92.20, 92.20)=92.20` → True。
3. 主链实现里「重叠优先」：`if _overlaps_zone(cand, zs_low, zs_high)` 先于「走出段」判断，
   所以 S11 被并入 ZS1 延伸本体（body=[8,9,10,11]），而不是被识别为走出段
   （S11 向下且 `low 85.70 < ZD 92.05`，本已满足走出条件）。
4. 吸收后扫描指针 `i = j = 12`，而主循环上限 `i < len(items)-4`（=12）不再满足，
   循环结束，S11/S12/S13/S14 与 S12/S13/S14/S15 两个窗口未被扫描。

## 3. S13/S14/S15 是否构成中枢

**几何上构成。** S13(下)/S14(上)/S15(下) 的三重叠加：

```
max(84.05, 84.05, 83.30) = 84.05
min(88.75, 89.35, 89.35) = 88.75
→ 区间 [84.05, 88.75]，有效
```

以 S12（上）为进入段，方向模式「反向-同向-反向」成立，且 S12 与 `[84.05, 88.75]` 重叠。
因此 S12(进)+S13/S14/S15 是一个合法的 segment 级中枢候选。它与 S11(进)+S12/S13/S14
（区间 `[85.70, 88.75]`）同样被「S11 被 ZS1 吸收 → 指针跳窗 → 循环上限截断」跳过。

## 4. 多义性与结合律视角

把 S8~S15 视为连续交替段，按结合律可以得到多组「三重叠加」中枢候选（含金量不同）：

| 核心段 | 方向 | 叠加区间 | 宽度 |
| --- | --- | --- | --- |
| S8/S9/S10 | 上/下/上 | [92.05, 92.20] | 0.15 |
| S9/S10/S11 | 下/上/下 | [89.80, 92.20] | 2.40 |
| S10/S11/S12 | 上/下/上 | 无（89.80 > 88.75） | — |
| S11/S12/S13 | 下/上/下 | [85.70, 88.75] | 3.05 |
| S12/S13/S14 | 上/下/上 | [85.70, 88.75] | 3.05 |
| S13/S14/S15 | 下/上/下 | [84.05, 88.75] | 4.70 |

观察：

- 同一段序列下存在 **5 组有效三重叠加**，这就是多义性：中枢边界并非唯一。
- 这些候选在 `[84, 92]` 一带相互重叠，说明 S8~S15 整体更像一个**更大级别的震荡区**，
  而非「一个 0.15 宽的薄中枢 + 一段游离的下跌」。
- 结合律只约束「分解前后段数量与方向交替不变」，不决定「哪一组叠加是中枢」；
  选择哪一组，取决于它能否让下游的「走势类型 → 最近中枢 → 一二三类买卖点」自洽。

## 5. 两种口径对比（评审对象）

| 维度 | 口径 A：重叠优先（现状，已冻结） | 口径 B：走出优先 |
| --- | --- | --- |
| 规则 | 后续段只要与固定区间有重叠就并入延伸本体；只有「完全不重叠 + 同向 + 突破」才判走出 | 同向且突破区间的段优先判走出，即便与区间仍有弱重叠 |
| 规范依据 | §5.1「重叠=扩展」、§10.1「固定前三段区间」、§6「不能只凭越界机械判定」 | §8「离开段单独表达，不并入本体」、§6 的「离开性质需解释」 |
| 稳定性 | 高：区间固定零漂移，confirmed/pending/auxiliary 清晰 | 高，但会改变一批既有边界 |
| 对 03690 5m | S11 并入 ZS1，S12/S13/S14 与 S13/S14/S15 被跳过 | S11 成为 ZS1 走出段，S12/S13/S14 或 S13/S14/S15 独立成中枢 |
| 对既有测试 | 满足 `test_fixed_zone_does_not_recompute_on_extension` | **会破坏该测试**（bi4 跌破 ZD 但仍重叠 → 现状延伸，口径 B 会判走出） |

张力本质：S11 这类「跌破 ZD 且与区间仅有 0.15 弱重叠」的段，两个口径给出相反结论。
`test_fixed_zone_does_not_recompute_on_extension` 里的 bi4（跌破 ZD 但仍重叠）与 S11
属于同一类形态，只是 bi4 的「跌破幅度小」、S11 的「跌破幅度大」；两者在「重叠=延伸」
口径下被一视同仁。

## 6. 评审结论

1. **现状行为与 §10.1 冻结决策一致**，不是需要立刻修复的缺陷。S11 被吸收、S12/S13/S14
   与 S13/S14/S15 被跳过，是「固定前三段区间 + 重叠即延伸」主链口径的边界效应。
2. **S13/S14/S15（与 S12/S13/S14）几何上均构成合法中枢**，只是未被主链口径扫描到。
3. **不建议单方面切换到「走出优先」**：它会推翻 §10.1 冻结决策并破坏既有回归，
   且 §6 明确反对「只凭价格越界机械判定中枢结束」。
4. 真正的张力在**多义性**：薄中枢 `[92.05, 92.20]` 不反映 S8~S15 的真实震荡（84~96）。
   更稳的处理方向不是改「重叠/走出」优先级，而是考虑
   （a）把 S8~S15 按更大级别震荡解释（中枢扩张/升级），或
   （b）在 review/图示层显式标注这种薄中枢的「弱确定性」，让消费端不把它当强结构。
